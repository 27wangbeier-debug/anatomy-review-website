# Forma — Anatomy review

A responsive anatomy study website with six body-system guides, 30 flashcards, randomized five-question quizzes, answer explanations, and progress saved in the browser.

## Run

No build or dependencies are required. From this directory:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Open the website using your environment's browser or port tooling. You may also open `index.html` directly. Internet access is optional for the Google Fonts stylesheet; system fonts are used as a fallback.

Study material is introductory and intended for education. Progress is stored only in the current browser's local storage.
